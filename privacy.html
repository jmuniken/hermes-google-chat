Privacy policy

Effective October 20, 2026

Hermes Google Chat is a personal-use Google Chat automation operated by Jerome Muniken. This policy covers the connected helper and this public informational website. It is not an official Google or employer-provided service.

Google account access

The helper uses the operator's explicit Google OAuth authorization, not their Google password. Its permissions allow reading Chat spaces and messages, reading reactions, creating reactions, and creating messages. The current local policy disables posting messages and restricts automated activity to one approved space and the 🇧🇪 reaction. Google authorization scopes can be broader than that local policy.

Data accessed and purpose

The helper accesses space metadata; message text, identifiers, timestamps and thread information; sender identifiers and available profile information; attachment metadata and selected images; and reaction identifiers, users and emoji. This information is used to assess qualifying positive team participation, add an approved reaction, avoid duplicates, recover interrupted scans, and verify actions.

AI processing and service providers

This is an AI-assisted workflow, not local-only text processing. Relevant message content and selected images can be sent through Hermes to the operator's configured AI inference provider for classification or image analysis. Provider processing and retention are governed by that provider's terms and the operator's account settings; this policy does not promise zero retention by those providers. Google processes API requests. GitHub hosts only this public website and its repository, not the helper's Chat records or credentials.

Local storage and retention

OAuth tokens, pending scan data, checkpoints, reaction decisions, message identifiers, audit records, downloaded image caches, and execution/session logs are stored on the operator's computer. Logs and pending batches can include message content and sender information. Records and cached images may remain until manually removed; no automatic deletion period is currently promised. Backups may retain copies according to the operator's backup settings.

Sharing and protection

The operator does not sell Chat data, publish it in this repository, use it for advertising, or use it to train their own general-purpose AI models. Data is processed only to operate and troubleshoot this helper, including necessary AI-provider processing described above. Credentials and application records are stored locally with restricted file permissions. Google access is revocable. No system can guarantee absolute security.

Your choices and deletion

The operator can pause the scheduled job, revoke the app's access in Google Account third-party connections, and delete the local OAuth token, application state, downloaded images and related logs. Revocation prevents future authorized access but does not automatically erase existing local records or data already processed by providers. Workspace administrator controls also apply. To request review or deletion of locally held records relating to you, contact the operator using the channel below without posting the underlying private content.

Website and contact

This static site contains no application analytics, advertising, forms or embedded AI tools. GitHub may process visitor connection information as its hosting service describes in its own privacy statement.

For questions or privacy requests, open a GitHub Issue. Issues are public. Do not include private Chat messages, attachments, credentials, account identifiers or other sensitive details. Ask for a private follow-up channel if needed. The operator will coordinate an appropriate response.

Changes

Material changes to this workflow or policy will be reflected on this page with an updated effective date.
